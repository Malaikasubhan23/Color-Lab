# MS ColorLab

**MS ColorLab** is a modern and creative color exploration website designed to help users explore, understand, and create with color.

## About the Project

The website provides a visually engaging space where users can learn about colors, explore different color combinations, and discover useful color palettes through a clean and futuristic interface.

## Features

- Home section with project introduction
- Explore section for discovering colors
- Interactive Color Wheel section
- Color Palettes section
- About section
- Modern futuristic design
- Responsive layout
- Clean navigation bar
- Visually focused color presentation

## Design

MS ColorLab uses a futuristic dark theme with vibrant cyan accents to create a modern digital experience.

### Color Theme

- Dark navy background
- Deep blue sections
- Bright cyan highlights
- High-contrast text and elements

## Technologies Used

- HTML5
- CSS3
